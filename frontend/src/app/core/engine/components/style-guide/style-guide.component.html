Typography

Headings from Bootstrap's scale; below body only two steps: --fs-sm and --fs-xs.

.h2 — Page title

.h4 — Section title

.h5 — Card title

.lead — Introduction

Body (--bs-body-font-size) — Running text that wraps onto several lines when the column is narrow, as real content does.

.small (--fs-sm) — Helper text, captions, menu items

.text-xs (--fs-xs) — Fine print, counters, codes

.font-monospace — IT12345678901

Spacing

One scale for utilities and component CSS: --space-N ≡ .p-N / .gap-N.

@for (step of spaceSteps; track step) {
--space-{{ step }}
}

Buttons

Default size for actions; .btn-sm only in dense toolbars; .btn-touch on any button used on its own (44px target).
